# API Resources (StoreEase)

Base URL: `/api/v1`
Format: JSON (camelCase)
IDs: Numeric (UUID optional for external refs)

## Resources

- **/auth**

  - User authentication (login, signup, token refresh)

- **/users**

  - View public user profiles

- **/items**

  - Browse, search, and filter store items

- **/carts**

  - Manage user cart (add, remove, update)

- **/orders**

  - Place new orders and track history

- **/payments**

  - Handle payment transactions

- **/notifications**

  - User notifications (low stock, restock alerts)

- **/store**
  - Store info (open/close timings, settings)
